# [NoMercy Status](https://status.nomercy.tv)

This repository contains the status page for [NoMercy Entertainment](https://nomercy.tv), powered by [Upptime](https://github.com/upptime/upptime).

Monitored today (see `.upptimerc.yml`): the website, the control plane API, the web
app, Keycloak auth, the CDN, the docs site and the package repository — seven checks,
run every five minutes.

Each check targets something only that service can serve. This matters: nomercy.tv,
api.nomercy.tv and cdn.nomercy.tv all sit behind the same Cloudflare front door, and a
bare `GET` on the apex of each returns the byte-identical page. Probing those apexes
would give three green rows that all measure the same thing, so the API is checked via
a real authenticated route, the CDN via a real asset, and auth via Keycloak's realm
document. Response-time ceilings are set per service, so a service that is reachable
but slow reports as degraded rather than up.

The media server is self-hosted by each user, so there is no instance for this page to
monitor and it is deliberately absent.

overwritten on every run.
